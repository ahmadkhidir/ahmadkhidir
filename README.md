## Selected work

**[Harness](https://github.com/ahmadkhidir/harness)** · Flutter
Mobile-first agent runtime. Multi-turn tool loops with parallel dispatch, bring-your-own model across
Gemini, Claude, OpenAI and an on-device LiteRT model, a sandboxed workspace with loadable skills, and
A2UI surfaces rendered as native widgets.

**[AegisMCP](https://github.com/ahmadkhidir/aegismcp)** · Java
Zero-trust reverse proxy for MCP tool calls. Policy as code, DLP scrubbing, human approvals, and a
hash-chained audit ledger. Built on the premise that an agent with unmonitored tool access is a
liability rather than a feature.

**[Sabi](https://github.com/vanguard-op/sabi)** · Python
Conversational agent that pays for Nigerian government services and bills in English or Pidgin.
Intent resolution, a hard confirmation gate, and payments isolated behind signed mandates and
idempotency keys.

**[Groundwork](https://github.com/ahmadkhidir/groundwork)** · Go
AI analytics where the model writes SQL, a disposable DuckDB engine executes it, and the model
narrates only over the returned rows. Every number traces back to a query.

**[GoGateway](https://github.com/ahmadkhidir/gogateway)** · Go
API gateway and reverse proxy from scratch. JWT and API-key auth, Redis rate limiting with in-memory
fallback, three-state circuit breaker, Prometheus metrics. Three external dependencies.

**[Vectr](https://github.com/vanguard-op/vectr)** · Rust
Vector graphics language and deterministic compiler that turns a description into editable SVG, PNG,
or PDF.
